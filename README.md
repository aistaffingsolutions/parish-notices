# parish-notices
Hourly GitHub Action that caches recent RIP.ie death notices as JSON for the
Cappagh, Croagh/Kilfinny and St Mary's & St Nicholas (Limerick) parish websites (rip.ie blocks Cloudflare's IPs, so
the scrape runs here on GitHub's network instead). Data: `data/cappagh.json`, `data/croagh.json`, `data/stmarys-stnicholas.json`.
